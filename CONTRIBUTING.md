# Contribuir

1. Crea una rama desde `main`.
2. Instala dependencias con `npm install`.
3. Ejecuta `npm run lint`, `npm run test` y `npm run build`.
4. Mantén el contenido de ejemplos ficticio y genérico.
5. Envía una solicitud de cambios pequeña y verificable.

Respeta el formato existente y evita dependencias que requieran servicios externos.
