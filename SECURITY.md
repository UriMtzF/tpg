# Seguridad

No se aceptan archivos ni claves privadas mediante el uso público de la aplicación. Los contenidos se procesan en el navegador y no deberían compartirse con terceros.

Para informar una vulnerabilidad, abre una incidencia privada de seguridad en el repositorio con una descripción reproducible y sin datos sensibles. No publiques secretos o pruebas explotables antes de que exista una corrección.
